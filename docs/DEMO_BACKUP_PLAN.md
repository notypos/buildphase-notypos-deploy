# Demo Backup Plan

## Primary Demo

Use the deployed production app:

<https://buildphase-notypos.vercel.app>

Recommended flow:

1. Open the app before presenting.
2. Confirm `/api/health` responds successfully.
3. Sign in to the prepared demo account if saved stack data is needed.
4. Keep one known-good supplement question ready.
5. Keep one known-good scanned label image ready.

## Backup Options

If venue Wi-Fi fails:

- Play the hosted demo video.
- Walk through screenshots or the pitch deck.
- Use the one-page handout to explain the flow.

If AI providers are slow:

- Show a previously saved Decision Card.
- Explain that retrieval refuses out-of-scope answers before model generation.
- Continue with My Stack deterministic dose checks, which do not need model
  generation for numeric safety logic.

If the camera scan fails:

- Use the typed My Stack entry form.
- Use a prepared label image file.
- Explain that the label scanner is additive; the evidence and dose-check flows
  still work without camera capture.

## Presenter Checklist

- Production app opened.
- Demo account credentials available privately.
- Demo video URL opened in a second tab.
- Pitch deck downloaded locally.
- Handout available from the repository.
- Browser zoom set to a readable level.
